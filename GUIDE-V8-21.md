# Ligue 1 Express V8.21 — Statistiques LIVE

## Contenu

- Statistiques réelles APIfootball dans le Centre Match LIVE.
- Possession, tirs, tirs cadrés, corners, fautes, hors-jeu et cartons.
- Comparaison domicile / extérieur avec jauges visuelles.
- Heure de dernière actualisation.
- Navigation rapide entre le fil du match et les statistiques.
- État propre lorsque la source n'a pas encore publié les chiffres.
- Affichage adapté aux mobiles.

## Installation

1. Copier le dossier de mise à jour dans le projet avec `robocopy /E`.
2. Lancer `npm.cmd run build`.
3. Publier les fichiers avec Git.

Aucun SQL, aucune variable Vercel et aucune modification du cron ne sont nécessaires.
