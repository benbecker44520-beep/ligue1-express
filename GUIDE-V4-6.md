# Ligue 1 Express — V4.6

## Nouveauté : fiches Clubs
- Cliquer sur une équipe depuis le classement ouvre `/club/[id]`.
- Le nom des équipes sur les fiches match est également cliquable.
- Le Top 5 de l’accueil mène aux fiches clubs.
- Chaque fiche affiche classement, points, J/G/N/P, différence de buts, 5 derniers matchs et 5 prochains matchs.
- Les matchs de la fiche club renvoient vers leur fiche match.

Aucune migration Supabase supplémentaire n’est nécessaire.
Copier votre `.env.local` existant dans ce dossier avant de lancer le site.
