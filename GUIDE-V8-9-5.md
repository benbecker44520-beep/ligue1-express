# V8.9.5 — Actualités mobiles compactes

Cette version améliore uniquement l'affichage mobile de la grille d'actualités :

- cartes compactes en défilement horizontal ;
- une carte principale visible à la fois avec aperçu de la suivante ;
- titre limité à 3 lignes ;
- résumé masqué sur mobile ;
- bouton compact « Lire → » ;
- aucun changement de données, Supabase ou variable d'environnement ;
- affichage desktop conservé.
