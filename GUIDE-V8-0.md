# Ligue 1 Express — V8.0

## Refonte Accueil & Live

Cette version transforme la page d'accueil en véritable hub média dynamique.

### Nouveautés
- Bandeau « En ce moment » : live/prochain match, dernière info mercato et dernière actu.
- Nouveau « Match à suivre » avec logos, score/heure et lien direct vers le centre match.
- Top 5 Ligue 1 intégré à la colonne principale.
- Nouveau bloc « Top buteurs » avec liens vers les fiches joueurs.
- Nouveau bloc « Forme du moment » calculé automatiquement sur les 5 derniers matchs terminés.
- Nouveau « Mercato Express » connecté à la table `transfers`.
- Prono conservé et mieux intégré dans la hiérarchie de l'accueil.
- Responsive mobile/tablette renforcé.

### Données utilisées
Aucune nouvelle base ni aucune nouvelle clé API : la V8.0 réutilise football-data.org, Supabase, les articles, pronostics et transferts existants.

### SQL
Aucun SQL à exécuter.
