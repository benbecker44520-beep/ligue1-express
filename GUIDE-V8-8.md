# V8.8 — Mes alertes + Mon Club enrichi

## Nouveautés
- Nouvelle page `/mes-alertes`.
- Préférences d’alertes enregistrées localement dans le navigateur.
- Détection automatique du club favori déjà choisi dans Mon Club.
- Choix des alertes : Fil Express, Mercato, Match, Résultats, Blessures, Coupe de France et Urgent.
- Demande d’autorisation des notifications navigateur + bouton de test local.
- Bouton cloche dans le header desktop et entrée Mes alertes dans le menu mobile.
- Mon Club affiche en priorité la dernière info Fil Express liée au club.
- L’API Mon Club récupère désormais les brèves Fil Express correspondantes.
- Raccourcis PWA LIVE / Fil Express / Mes alertes.

## Important
Cette version prépare le modèle de préférences qui sera réutilisé pour l’application mobile. Le test navigateur est local : les notifications push en arrière-plan iOS/Android seront branchées dans une version dédiée.

## Déploiement
Aucun nouveau SQL Supabase.
Aucune nouvelle variable Vercel.
