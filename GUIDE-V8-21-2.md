# Ligue 1 Express V8.21.2

## Nouvelle présentation des faits marquants

- Actions de l'équipe à domicile affichées à gauche.
- Actions de l'équipe extérieure affichées à droite.
- Minute et icône placées sur la ligne centrale.
- Présentation adaptée aux écrans mobiles.

## Installation

Copier les fichiers dans le projet, lancer `npm.cmd run build`, puis publier avec Git.

Aucun SQL et aucune nouvelle variable Vercel ne sont nécessaires.
