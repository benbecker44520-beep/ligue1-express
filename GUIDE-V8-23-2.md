# Ligue 1 Express V8.23.2

Correction des statistiques joueurs lorsque le fournisseur utilise un prénom abrégé, par exemple « O. Dembélé » au lieu de « Ousmane Dembélé ».

La recherche essaie désormais le nom complet, puis le nom de famille avec contrôle de l'initiale pour éviter les homonymes.

Aucun SQL supplémentaire n'est nécessaire.
